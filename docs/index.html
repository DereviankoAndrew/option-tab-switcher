Why it feels right

Built around how you actually switch.

Ctrl+Tab goes through tabs from left to right. You usually want the tab you were just on. ⌘Tab got that right years ago.

A quick tap takes you back

A quick tap of ⌥ Tab flips between your two latest tabs. Released quickly, it switches without the switcher flashing on screen.

Hold to browse

Keep ⌥ down and the switcher shows up. Tab moves right, ⇧ Tab or ` moves left, and letting go switches.

Works across all windows

The list covers tabs in every Chrome window. Picking a tab in another window brings that window to the front, just like ⌘Tab with apps.

Close tabs from the switcher

Press Q or W while the switcher is open to close the selected tab, the same way ⌘Tab + Q quits an app.

Looks like macOS

A frosted-glass panel that follows light and dark mode. It's rendered in an isolated shadow DOM, so websites can't break its styling.

Private by design

No servers, analytics or accounts. The tab order lives in your browser's session memory and nowhere else.

Install

Up and running in a minute.

Until it's on the Chrome Web Store, you install it as an unpacked extension.

Download

Get option-tab-switcher.zip and unzip it somewhere permanent.

Open extensions

Go to chrome://extensions in Chrome.

Developer mode

Turn on Developer mode in the top-right corner.

Load unpacked

Click Load unpacked and choose the unzipped folder. Then try ⌥Tab.

FAQ

Questions & limits

Why doesn't ⌥ Tab work on the New Tab page or chrome:// pages?

Chrome's shortcut API doesn't accept Tab as a key and can't detect when you let go of a modifier. Both are needed for ⌘Tab-style switching, so the extension catches the keys inside the web page instead. Chrome doesn't let extensions run on its own pages: the New Tab page, chrome:// pages and the Web Store. For those, you can bind a fallback "switch to previous tab" shortcut at chrome://extensions/shortcuts.

It doesn't react when I'm typing in the address bar.

Same reason: the address bar and DevTools belong to Chrome itself, not the page. Click into the page or press Esc first.

What permissions does it need, and why?

tabs to list and switch tabs, storage to remember the order while the background worker sleeps, favicon to show site icons, and scripting plus access to all sites to listen for ⌥ Tab on every page. Nothing is sent anywhere.

Does it work on Windows or Linux?

It's built for macOS. On Windows and most Linux desktops, Alt+Tab is taken by the operating system before Chrome ever sees it.

Another app already uses ⌥ Tab (e.g. a window switcher).

Apps that grab ⌥ Tab system-wide get it first. Change the shortcut in that app, or use the fallback command.
